# 三色桌宠

三色桌宠基于黑猫桌宠改编。两个平台均可在蓝色的 DeepSeek、橙色的 Claude 和白色的 Codex 之间切换。首次启动显示 DeepSeek 并开启打字声。

## 使用

- **换角色或静音**　右键点击人物，在菜单里选择角色或勾选「静音」。Mac 还可以点菜单栏的「三色」。角色和静音状态在下次启动时恢复，静音时键盘动作照常显示。
- **Mac 预览选择栏**　顶部控件默认隐藏。右键人物，勾选或取消「显示顶部控件」即可展开或收起角色与静音选项。预览窗口会记住这个设置。
- **大小**　右键人物，打开「大小」，选择 50%、75%、100%、125%、150% 或 200%。两个平台都会记住上次的比例。
- **跟着打字和移动鼠标**　桌宠的小键盘上有 48 个可响应的键，打字时由角色相应的一只手按下并点亮键帽。移动桌面光标时，人物右手握着小鼠标在键盘旁滑动。这时按 D、F 或空格，左手仍可以敲键。按 J 等右手键时，右手会从鼠标移向键盘。
- **空闲时的小动作**　连续约 45 秒没有键鼠输入，蓝色 DeepSeek 会捧起鲸鱼纹饭碗，用筷子吃白饭。橙色 Claude 会打开太阳花封面的书，低头阅读、翻页并合书。白色 Codex 会把蓝色云朵玩偶从手心抛起，注视它升起再落下，伸手接住。移动鼠标或按键会立即打断这段动作。
- **表情**　日常待机时，角色每隔约 4–8 秒随机换一次表情，停留约 1–2 秒，相邻两次不同。进餐时会从期待换成满足，读书时会专注或会心一笑，抛接玩偶时会随着离手和接住改变表情。
- **犯困和睡醒**　约 57 秒时角色收起道具，开始犯困。约 60 秒后闭眼睡着，头顶浮出 Zzz。蓝色角色的鲸尾保持自然轮廓，橙色的发梢和白色的龙尾逐渐放低。按键或动鼠标可以唤醒她。她会轻轻摇头，第一下敲键也会照常响应。
- **摸头**　轻点或来回轻抚，角色会微笑并飘出爱心。在头顶按住约 0.35 秒，她会眯眼向手指的位置轻蹭，松开后放松。如果要移动窗口，可以从身体开始拖动，或在头顶按下后立即拖动。
- **登录时启动**　右键勾选「登录时启动」后，下次登录当前账户时自动打开。默认关闭。Mac 建议先移入「应用程序」。Windows 请先将 EXE 放入固定目录。
- **移动和退出**　左键拖动桌宠可改变它的位置。右键菜单中选择「退出三色桌宠」。
- **头部和眼神跟随**　将光标移到桌宠的左、右、上、下，眼睛会先看过去，头部稍后跟随。光标停住后角色继续看着落点。眨眼和摸头微笑时，闭合的眼皮随头转动。
- **Mac 键盘权限**　在其他软件里打字时，让桌宠跟随按键需要给「三色桌宠」授予输入监控权限。可以从菜单的「开启输入监控…」进入设置。预览窗口内的打字和移动鼠标可以直接测试。
- **键鼠方向**　人物面对观看者。空格排在靠近人物的一侧，数字排在靠近观看者的一侧，键帽文字按人物视角排列。鼠标在画面左侧，掌托朝向人物右腕，按键和滚轮斜向画面左下方。弹出的按键标签供观看者阅读。

## 构建

Mac 需要 Xcode 命令行工具及 macOS SDK。运行以下命令会将三个角色和声音打入应用，执行资源自检，再进行本地签名。

```sh
bash build-mac.sh
./build/三色桌宠.app/Contents/MacOS/TriColorPet --preview
```

对外分发 Mac 版时，指定本机钥匙串里的 Developer ID Application 签名身份。脚本会启用强化运行时并请求安全时间戳。若已通过 `xcrun notarytool store-credentials` 配好钥匙串凭据，可对同一个已签名的 App 提交 Apple 公证、装订票据，并生成和核验分发 ZIP。以下命令在 `BlackCat` 目录运行。

```sh
MACOS_SIGN_IDENTITY='Developer ID Application: <name> (<team-id>)' bash build-mac.sh
bash tools/notarize-mac.sh build/三色桌宠.app "你的钥匙串配置名称" build/TricolorPet-macOS.zip
```

Windows 版本面向 x64。以下命令可在装有 Go 的 Mac 上交叉构建。

```sh
mkdir -p build
(cd windows && GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go build -trimpath -ldflags='-s -w -H=windowsgui' -o '../build/三色桌宠-Windows-x64.exe' main.go)
```

在 Windows PowerShell 中，从项目根目录构建可使用以下命令。

```powershell
New-Item -ItemType Directory -Force build | Out-Null
Set-Location windows
$env:GOOS='windows'
$env:GOARCH='amd64'
$env:CGO_ENABLED='0'
go build -trimpath -ldflags='-s -w -H=windowsgui' -o '../build/三色桌宠-Windows-x64.exe' main.go
```

## 角色素材与动作

三个角色的动作以 `Artwork/blue.png`、`amber.png`、`frost.png` 的正面待机图为准。`hand-rig.json` 标定肩袖、肘、手腕、指尖与轮廓；`underlay.png` 补出手臂移开后露出的头发和衣料。打字和握鼠均只移动操作侧的手臂与手指。键盘仍在人物前方，按下的键会高亮。`smile.png` 与 `expression-rig.json` 提供眉眼和嘴部的局部表情，摸头时，局部表情叠加在当前手部姿势上。动作素材的分格与绘制说明见 `Artwork/素材说明.md`。

两个平台共用三份角色图集。蓝色有 288 帧，橙色有 285 帧，白色有 290 帧。其中每位角色各有 240 张 600 × 250 像素按键补图，其余为 600 × 540 像素的姿势、表情或道具图层。单次敲键包括抬手、前伸、触键、回弹和收回。快打期间优先显示新键触底，握鼠与键盘间有四个抬腕姿势。`half-face.png` 提供三位角色的半闭眼与浅笑。运行时用待机图的上部与对应补图拼成完整画面，再按光标方向调整头部与虹膜，最后按选定尺寸显示。默认桌面尺寸为 300 × 270 逻辑单位。橙色和白色角色各用四个姿势放低发梢或龙尾。鼠标和握住它的手掌绘在同一图层，滑动时从固定的肩部逐渐过渡到手腕和鼠标的同步位移。握住鼠标的手臂取自 `Artwork/mouse.png` 中每位角色自己的握鼠姿势，接触点跟随鼠标按键的方向和位置。

修改动作美术后，从项目根目录运行以下命令。前两行更新 `windows/assets` 中的动作 PNG，第三行使用 Go 1.21 或更高版本生成两个平台共用的无损图集和帧索引。每个角色的相同 8 × 8 像素块只存一份。

```sh
clang -O3 -fobjc-arc -framework Cocoa -framework ImageIO windows/export.m -o /tmp/tricolor-frame-export
/tmp/tricolor-frame-export Artwork windows/assets
go run tools/packframes/main.go
```

若调整了待机图的脸部位置或眼睛轮廓，更新 `tools/generate-gaze.py` 的标注，再用装有 NumPy 和 Pillow 的 Python 3 运行该脚本，生成三个角色的视线位移数据。

`Cat.m` 管理 AppKit 悬浮窗口、输入监控、预览、菜单、声音和角色偏好。`windows/main.go` 管理 Win32 分层窗口、键盘 Raw Input、光标跟随、右键菜单和本机偏好。发布包使用 `windows/packed` 中的角色图集和索引、`windows/gaze` 的视线数据及三个 WAV。
